# 执行前预检与调用方式

预检的目标是找到**实际可用的调用方式**，不是要求命令全局安装。
只做定位与验证，不安装依赖、不修复环境、不写入知识库，不调用网络或模型。

## 1. 分清两个目录

- `VAULT_ROOT`：本次操作的知识库绝对路径，来自用户指定或已确认的任务上下文。
- `REPO_ROOT`：可选的工具源码目录，来自用户指定、已有配置或已知仓库位置。
  用 `pyproject.toml` 和 `src/octopus_kb_compound/` 确认身份。

二者可以不同。当前目录、技能安装目录都不一定是工具仓库或知识库。
只检查明确的候选位置；无法定位时报告缺少的路径，不遍历整台机器。
用户指定源码版本时，优先验证该仓库环境，不用另一份全局安装替代。

## 2. 定位候选并实际验证

默认按下面顺序尝试；每个候选设置有限超时（例如 15 秒），同一候选失败后不原样重试。

1. 用 `command -v octopus-kb` 定位 PATH 中的命令。取得可执行文件的绝对路径后，
   执行该路径的 `--help`，确认退出码为 `0`，输出确实是本工具的子命令帮助。
2. 若没有可用的 PATH 命令，但已定位源码仓库，实际执行
   `"<REPO_ROOT>/.venv/bin/octopus-kb" --help`。
   **文件存在不代表可用**：旧入口可能仍引用移动或改名前的路径。
3. 若包装入口失败或不存在，尝试源码方式。优先使用
   `<REPO_ROOT>/.venv/bin/python`；若不可用，再检查用户明确指定的解释器或
   `command -v python3` 找到的解释器。不要断言系统 Python 必然缺依赖。
   对候选解释器分别验证导入和模块入口，路径必须替换为真实绝对路径：

   ```bash
   PYTHONPATH="<REPO_ROOT>/src" "<PYTHON_ABSOLUTE_PATH>" -c 'import octopus_kb_compound; print(octopus_kb_compound.__file__)'
   PYTHONPATH="<REPO_ROOT>/src" "<PYTHON_ABSOLUTE_PATH>" -m octopus_kb_compound.cli --help
   ```

   确认包位置属于指定仓库，且两条命令都成功。`PYTHONPATH` 只定位源码，
   不会安装依赖；模块入口仍可能因缺少 `yaml` 等包而失败。

只检查当前任务需要的可选能力：本地文件转换需要额外验证选定解释器能导入
`markitdown`；真正提出模型建议时才检查模型配置。帮助成功不证明所有格式、
模型服务或网络都可用；单纯检索不需要先调用模型或验证其服务。

## 3. 锁定并复用执行方式

在当前任务上下文记录：

- `argv_prefix`：已验证的绝对命令路径，或 `[解释器绝对路径, "-m", "octopus_kb_compound.cli"]`。
- `env`：源码方式所需的 `PYTHONPATH=<REPO_ROOT>/src`；其他方式不凭空添加。
- `cwd`：`VAULT_ROOT`。技能示例中的 `--vault .`、`raw/...` 等相对路径均以此为基准。

示例里的 `octopus-kb` 是调用方式的占位符，执行时换成上述前缀。
使用参数数组；通过 shell 调用时正确引用包含空格的路径，不使用 `eval` 拼接命令。
不依赖跨工具调用持续生效的 `source activate`，也不把工作目录切到工具仓库后误操作它。
同一任务复用验证结果，不在每条业务命令前重复探测；路径、解释器或环境变化，
或出现执行体/导入错误时再重新预检。知识库路径变化时更新 `cwd` 与路径参数。

## 4. 失败时准确说明原因

所有明确候选都失败才停止业务操作，列出尝试的路径、退出码和必要错误摘要：

- 没有定位到命令或源码：说明还缺工具位置，不直接断言“本机没安装”。
- 入口引用旧目录：说明包装脚本路径失效；源码后备成功时继续任务，不强制重装。
- 缺少依赖：指出实际报错的模块和解释器，给出针对该环境的安装建议。
- 知识库路径缺失或无效：单独报告，不能误判为工具未安装。

预检本身不运行 `sudo`、全局 `pip install`、删除或重建虚拟环境。
如需安装或修复，按用户已有授权处理；没有相关授权时说明具体动作后再请求确认。
不输出密钥或完整环境变量。

执行业务命令后，结合退出码和结构化结果判断：检索 marker 的 stderr 警告不代表失败，
`lint` 发现问题也不代表环境缺失，`validate` 的拒绝/待复核结果更不应触发安装重试。
